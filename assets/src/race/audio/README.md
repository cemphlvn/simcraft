# Race audio: what to download (CC0 only)

Drop the files here with these names (any of .wav / .flac / .mp3 / .ogg). I cut, loop, level and wire them.
Every link is a freesound.org search already filtered to CC0 (public domain: no credit needed, use anywhere).
Download needs a free freesound account. Prefer: onboard or close-mic recordings, steady (not revving
up and down), 44.1 kHz or higher, at least 5 s, no talking/music.

| file name | what | search (CC0) |
|---|---|---|
| `engine_low.*` | V8 at low rpm under load (~3,000-4,500), onboard or close | https://freesound.org/search/?q=v8+engine+onboard&f=license%3A%22Creative+Commons+0%22 |
| `engine_mid.*` | V8 mid rpm under load (~5,500-7,000) | https://freesound.org/search/?q=v8+race+car+engine&f=license%3A%22Creative+Commons+0%22 |
| `engine_high.*` | V8 high rpm flat out (~8,000-9,500), NASCAR / stock car if possible | https://freesound.org/search/?q=nascar&f=license%3A%22Creative+Commons+0%22 |
| `engine_off.*` | V8 off throttle / coasting, crackles (engine braking) | https://freesound.org/search/?q=engine+decel+crackle&f=license%3A%22Creative+Commons+0%22 |
| `engine_idle.*` | V8 idle, lumpy race cam | https://freesound.org/search/?q=v8+idle&f=license%3A%22Creative+Commons+0%22 |
| `passby.*` | race car passing at speed (for the other cars) | https://freesound.org/search/?q=race+car+pass+by&f=license%3A%22Creative+Commons+0%22 |
| `tyre_squeal.*` | tyre squeal / scrub, steady | https://freesound.org/search/?q=tire+squeal&f=license%3A%22Creative+Commons+0%22 |
| `scrape.*` | metal scraping along a wall | https://freesound.org/search/?q=metal+scrape&f=license%3A%22Creative+Commons+0%22 |
| `impact.*` | car crash / heavy metal impact | https://freesound.org/search/?q=car+crash+impact&f=license%3A%22Creative+Commons+0%22 |
| `shift.*` | gear shift clunk (sequential or manual) | https://freesound.org/search/?q=gear+shift&f=license%3A%22Creative+Commons+0%22 |
| `crowd.*` | stadium / speedway crowd ambience | https://freesound.org/search/?q=stadium+crowd+ambience&f=license%3A%22Creative+Commons+0%22 |
| `wind.*` | wind noise at speed (car window / helmet) | https://freesound.org/search/?q=wind+noise+car&f=license%3A%22Creative+Commons+0%22 |
| `music_menu.*` | menu music, driving rock / country rock instrumental | https://freesound.org/search/?q=rock+instrumental+loop&f=license%3A%22Creative+Commons+0%22 |
| `music_results.*` | results / victory lap music | https://freesound.org/search/?q=victory+rock&f=license%3A%22Creative+Commons+0%22 |

If one engine recording covers a steady sweep from idle to redline, that single file (`engine_sweep.*`) can
replace the first three: I slice it into rpm bands.
